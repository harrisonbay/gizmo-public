# GZ-0009: first evolved MFM gradient pass produces localized force spikes

- Status: under investigation
- Confidence: medium
- Affected configuration: 1-D periodic
  `HYDRO_MESHLESS_FINITE_MASS`, `SELFGRAVITY_OFF`,
  `FORCE_EQUAL_TIMESTEPS`
- Oracle: corrected-C/Rust endpoint differential plus smooth-wave invariant

## Evidence

An observation-only snapshot immediately after the first
`do_second_halfstep_kick()` isolates the two half-kicks. Rust and C agree on
the first half-kick to `6.6e-18` absolute velocity and agree at the endpoint on
position, predicted velocity, density, pressure, closure error, internal-energy
rate, and velocity gradient.

The second C hydro acceleration nevertheless differs from the Rust all-pairs
operator by as much as `1.3791e-6`. Instrumenting the endpoint gradient state
localizes the difference to density and pressure gradients. The C result has
isolated density-gradient values near `1.25e-5`, approximately twice the smooth
fundamental-mode derivative, and acceleration spikes up to `4.1046e-6`; the
linear sound-wave force scale is about `2.79e-6`. The affected particles cluster
near IDs 34-49 and 1999-2018 after the tree/domain reorder.

Standard snapshots cannot reveal this phase cleanly: they are written during
the drift, and `io.c` explicitly notes that their velocity is staggered.
`post-kick-snapshot.patch` therefore pins the observation point used here.

## Reproduce or falsify

Run the pinned one-rank sound-wave profile with the observation-only post-kick
patch. Record `SphP[].HydroAccel`, `Gradients.Density`, and
`Gradients.Pressure` after the endpoint hydro calculation and before the second
kick. Compare them by particle ID with a direct all-pairs implementation of the
same 1-D kernel, limiter, face, and Riemann equations.

Falsify this finding by showing that the localized C gradients are the intended
result of a documented discrete operator and that an independent reference
implementation reproduces them without the tree traversal, or by identifying
an error in the diagnostic state phase or field conversion.

## Current boundary

The divergence is confirmed, but attribution is not. Tree-neighbor duplication,
gradient accumulation, and limiter state are the leading areas to inspect.
Until one is proven, the Rust gate validates the exactly matching first
half-kick and endpoint scalar state but explicitly refuses to claim second-kick
velocity parity.

## Impact

If the localized force spikes originate in neighbor enumeration or gradient
accumulation, they inject tree-layout-dependent momentum errors into otherwise
smooth MFM flows. If the Rust all-pairs operator is missing an intended C
semantic instead, the Rust port's endpoint momentum update remains incomplete.
Either interpretation blocks treating a normal C snapshot as an unquestioned
evolution oracle.
