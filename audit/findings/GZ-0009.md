# GZ-0009: apparent first-step force spikes were a missing Rust predictor semantic

- Status: rejected
- Confidence: high
- Affected configuration: 1-D periodic
  `HYDRO_MESHLESS_FINITE_MASS`, `SELFGRAVITY_OFF`,
  `FORCE_EQUAL_TIMESTEPS`
- Oracle: corrected-C/Rust endpoint differential plus direct all-pairs
  reconstruction

## Resolution

The suspected C tree/gradient defect is falsified. A direct all-pairs
implementation using the exact C endpoint primitives and smoothing lengths
reproduces every instrumented C density, pressure, and velocity gradient to
floating-point precision (maximum absolute discrepancy `6.8e-21`).

The Rust KDK driver omitted the smoothing-length predictor in `predict.c`.
GIZMO carries the density-loop `Particle_DivVel` estimate into the drift and
seeds the next density solve with

```text
h_new = h_old * exp(clamp(Particle_DivVel * dt, -0.3, 0.3) / NUMDIMS).
```

Rust instead seeded the endpoint solve with `h_old`. Both seeds satisfy the
loose neighbor tolerance, so neither is iterated. Their difference is only
about `1e-13` absolute, but some neighbors lie exactly at the two-spacing
support boundary. That tiny change flips union-support membership used to
collect slope-limiter extrema and produces the apparently localized gradient
differences.

After porting the target-kernel `Particle_DivVel` estimator and predictor,
the completed Rust first KDK step agrees with corrected C at approximately
machine precision: position is exact, maximum velocity error is `1.1e-17`,
and relative density, internal-energy, and smoothing-length errors are
`2.3e-16`, `1.4e-16`, and `1.2e-16`.

## Evidence

The density estimator uses the target kernel only, includes self in its kernel
normalization, excludes self from the velocity-divergence numerator, and
applies the density-loop `DhsmlNgbFactor`. The predictor then evolves `Hsml`
before the endpoint density solve. These semantics are distinct from the MLS
velocity gradient.

The observation-only `post-kick-snapshot.patch` remains useful because normal
snapshots are written during drift with staggered velocity. The pinned
`evolution_step1.csv.gz` table gates both half-kicks and the completed state.

## Impact

No C correctness defect was established. The exercise exposed a numerically
sensitive but intended predictor dependency that a port must preserve. Treating
an accepted adaptive-`Hsml` solve as a unique mathematical solution is unsafe
when neighbor support and limiter extrema change discontinuously at its
boundary.
