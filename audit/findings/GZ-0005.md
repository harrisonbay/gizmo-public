# GZ-0005: meshless hydro reads an uninitialized target timestep

- Status: confirmed
- Confidence: high
- Affected flags: `HYDRO_MESHLESS_FINITE_MASS`,
  `HYDRO_MESHLESS_FINITE_VOLUME`, `HYDRO_SPH`
- Oracle: static analysis (static)

## Evidence

`hydro_force_evaluate()` declares the local `dt_hydrostep_i` without an
initializer and consumes it in the neighbor loop before any assignment.
Clang diagnoses the undefined read in a minimal public sound-wave build. The
communication input already has a `dt_hydrostep_i` field populated by
`particle2in_hydra()`, so the missing initialization is directly recoverable.

The regression is also isolated in history. Immediately before commit
`3d59d861`, this function assigned
`dt_hydrostep_i = local.Timestep * UNIT_INTEGERTIME_IN_PHYSICAL`. That commit
moved the converted value into the communication structure as
`local.dt_hydrostep_i` but deleted the target-side assignment. Restoring
`dt_hydrostep_i = local.dt_hydrostep_i` preserves the old units and works for
both local and imported targets.

[first undefined read](https://github.com/pfhopkins/gizmo-public/blob/a828c4ba79d67093bd1a3d04f6f90b5d2d94d65f/hydro/hydro_evaluate.h#L154-L156),
[input field](https://github.com/pfhopkins/gizmo-public/blob/a828c4ba79d67093bd1a3d04f6f90b5d2d94d65f/hydro/hydro_toplevel.c#L192),
[input assignment](https://github.com/pfhopkins/gizmo-public/blob/a828c4ba79d67093bd1a3d04f6f90b5d2d94d65f/hydro/hydro_toplevel.c#L419),
and [SPH viscosity use](https://github.com/pfhopkins/gizmo-public/blob/a828c4ba79d67093bd1a3d04f6f90b5d2d94d65f/hydro/hydro_core_sph.h#L178-L199).

## Reproduce or falsify

Compile a meshless hydro configuration with Clang warnings enabled. Reproduction
is the definite-uninitialized warning at the first `DMAX` followed by use in
`hydro_core_meshless.h`. Falsify by identifying a dominating assignment on
every preprocessed path.

The shared value is formed before the solver branch. Meshless solvers consume
it in reconstruction and flux limiting; `HYDRO_SPH` consumes it in the
artificial-viscosity limiter in `hydro/hydro_core_sph.h`.

## Impact

Undefined stack data can alter meshless reconstruction and fluxes or SPH
artificial viscosity, making scientific output compiler- and stack-layout
dependent.
