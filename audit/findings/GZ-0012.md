# GZ-0012: accumulated output time creates a nonconservative terminal dust snapshot

- Status: fixed
- Confidence: high
- Affected configuration: regularly spaced outputs ending at `TimeMax`,
  especially `GRAIN_FLUID` with `GRAIN_BACKREACTION`
- Oracle: byte-pinned public dustybox IC, analytic Epstein solution, and total
  momentum

## Evidence

`find_next_outputtime()` repeatedly adds `TimeBetSnapshot` in binary floating
point and truncates the resulting physical time to an integer timebase tick.
For the public dustybox values, 250 additions of `0.01` produce
`2.4999999999999907`, several thousand ticks below the exact terminal tick at
`2.5`. The code therefore writes the ordinary terminal drift as
`snapshot_250`, performs the endpoint force and kick, and then writes a second
`snapshot_251` because `Ti_lastoutput != Ti_Current`.

That distinction is scientifically observable because grain backreaction is
applied directly to gas velocity during the endpoint force, while the grain
receives the corresponding acceleration through leapfrog kicks. Ordinary
drift snapshots use the documented staggered-velocity phase and conserve
momentum. The extra final snapshot exposes the endpoint's unmatched half-step.

In the one-rank public dustybox reproduction:

- scheduled `snapshot_250` at `2.4999999999999907` has
  `mean(v_g)+mean(v_d)=0.9999999999999869`;
- duplicate `snapshot_251` at `2.5` has
  `mean(v_g)+mean(v_d)=1.0000002369145602`;
- the spurious total-velocity change is `2.369145733e-7`.

The weak dusty-wave case contains the same phase defect, but its much smaller
relative velocity hides it near floating-point noise.

## Fix

Regular output schedules now retain an integer output index and independently
evaluate that index to recognize a mathematical terminal output, avoiding
unbounded error from repeated addition or multiplication. Output times within
64 machine epsilons of `TimeMax` then map directly to the terminal integer
tick. The normal scheduled drift is written once at exact `t=2.5`, and the
final-output guard recognizes that the terminal tick was already emitted. This
preserves the established snapshot velocity phase and eliminates the
misleading duplicate.

The corrected public dustybox run writes 251 snapshots. Its terminal mean
velocity sum is `0.9999999999999869`, and its gas/dust velocities differ from
the published analytic Epstein solution by equal-and-opposite
`1.23367e-7`.
