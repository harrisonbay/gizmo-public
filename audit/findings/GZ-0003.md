# GZ-0003: chemistry ion lookup has a missing return

- Status: confirmed
- Confidence: high
- Affected flags: `SIMPLE_STEADYSTATE_CHEMISTRY`
- Oracle: sanitizer (dynamic)

## Evidence

`ion_name_to_index()` returns only on a matching name. The pinned function falls through for unknown input despite returning `int`, and its result is used as a recombination-table index.

Pinned source: [lookup fall-through](https://github.com/pfhopkins/gizmo-public/blob/a828c4ba79d67093bd1a3d04f6f90b5d2d94d65f/cooling/simple_chemistry.c#L42-L54).

## Reproduce or falsify

With the chemistry flag and UBSan enabled, pass an unlisted ion such as `Xe+`. Falsify by establishing an enforceable closed-set caller contract; ordinary caller convention is not sufficient.

## Impact

Undefined behavior can lead to out-of-bounds reads, corrupt rates, or a crash.
