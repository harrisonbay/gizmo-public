# GZ-0006: ideal-gas HLLC vacuum threshold suppresses non-vacuum pressure

- Status: confirmed
- Confidence: high
- Affected flags: `HYDRO_MESHLESS_FINITE_MASS`,
  `HYDRO_MESHLESS_FINITE_VOLUME`
- Oracle: exact reference criterion (exact)

## Evidence

The default nonmagnetic solver calls `get_wavespeeds_and_pressure_star()`.
Before estimating an HLLC star state, that function classified the interface as
vacuum whenever

```text
v_R - v_L > max(c_L, c_R).
```

It then set the star pressure to `MIN_REAL_NUMBER` (`1e-56`) and the contact
speed to zero. In MFM, the pair momentum flux is the star pressure times the
face normal, so this branch nearly eliminates the pressure force.

The exact ideal-gas solver in the same file independently applies the standard
two-rarefaction vacuum condition

```text
v_R - v_L > 2 (c_L + c_R) / (gamma - 1).
```

Pinned source: [legacy HLLC vacuum guard](https://github.com/pfhopkins/gizmo-public/blob/a828c4ba79d67093bd1a3d04f6f90b5d2d94d65f/hydro/reimann.h#L533-L537)
and [exact-solver criterion](https://github.com/pfhopkins/gizmo-public/blob/a828c4ba79d67093bd1a3d04f6f90b5d2d94d65f/hydro/reimann.h#L1034-L1042).
The shortcut dates to the initial public Git import, commit `6096d8ca`.

For equal sound speeds and `gamma=5/3`, the legacy threshold is `c`, while the
physical threshold is `6c`. Symmetric states immediately below the legacy
threshold retain a finite estimated star pressure; immediately above it jump to
`1e-56`, despite remaining far from physical vacuum.

## Reproduce or falsify

Use equal positive density and pressure on both sides, with equal sound speed
and symmetric separating velocities. Sweep the normal velocity jump across
`c`. The legacy guard changes the MFM momentum flux discontinuously to
approximately zero, while the exact criterion remains non-vacuum until `6c`.

Falsify this finding by deriving the one-sound-speed condition for an ideal-gas
vacuum, or by demonstrating convergence to the exact non-vacuum Riemann solution
throughout the interval between the two thresholds.

## Fix

For the ideal-gas HLLC path, the explicit guard now uses the same
`GAMMA_G4 * (c_L + c_R)` threshold as the exact solver. Failed non-vacuum HLLC
pressure estimates also remain negative or non-finite so the existing
KT/exact-solver fallback chain can run; previously three conversions to the
positive `MIN_REAL_NUMBER` sentinel made those retry checks unreachable.
`EOS_GENERAL` retains the old conservative threshold because this code has no
general-EOS rarefaction integral from which to derive a replacement.

## Impact

The old branch could remove pressure coupling in ordinary strong rarefactions,
creating a solver-induced discontinuity and potentially changing shocks,
outflows, and expansion problems well before a physical vacuum forms.
