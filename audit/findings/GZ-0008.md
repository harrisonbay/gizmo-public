# GZ-0008: exact Riemann iteration confuses numerical failure with vacuum

- Status: confirmed
- Confidence: high
- Affected configuration: nonmagnetic ideal-gas
  `HYDRO_MESHLESS_FINITE_MASS` or `HYDRO_MESHLESS_FINITE_VOLUME`, without
  `COOLING` or `GALSF`
- Oracle: mutually exclusive solver outcomes (property)

## Evidence

`iterative_Riemann_solver()` returned zero both when the closed-form
two-rarefaction check found a physical vacuum and when Newton iteration reached
its 1,000-iteration limit. `Riemann_solver_exact()` treated every zero return as
vacuum and sampled a zero-pressure solution.

The Newton loop also lacked finite checks. If an update made `tol` NaN, the
`tol > TOL_ITER` loop condition became false. Because success was decided only
by `niter_Riemann < NMAX_ITER`, that non-finite state was reported as converged.

Finally, the initial PVRS pressure estimate used

```text
(velocity jump) (p_L + p_R) (c_L + c_R)
```

in a pressure correction. The standard dimensionally consistent term uses
`rho_L + rho_R`; the pressure sum gives the correction the wrong units. This
does not change a converged root, but it can make convergence less robust.

## Reproduce or falsify

Instrument the iteration to force either exhaustion or a non-finite pressure
update. Before the fix, exhaustion enters the same internal-vacuum sampler as a
physical rarefaction, while a NaN tolerance can leave the loop and return
success.

Falsify the finding by proving all arithmetic remains finite and the iteration
always converges before its cap for every positive input state, or by showing a
distinct numerical-failure status reaches the caller.

## Fix

The solver now returns three distinct statuses: positive for convergence, zero
for physical vacuum, and negative for numerical failure. It checks the pressure,
wave curves, derivative, and tolerance for finite positive values; the wrapper
returns NaN on numerical failure so the existing reconstruction retry path is
activated. Equality at the vacuum boundary is handled as the zero-pressure
limit, and the PVRS seed now uses the density sum.

## Impact

The old behavior could silently remove pressure forces at a difficult
non-vacuum interface or accept a non-finite exact state. Both outcomes defeat
the purpose of the final exact fallback and can introduce sharp,
state-dependent errors.
