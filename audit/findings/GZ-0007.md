# GZ-0007: exact MFM Riemann fallback returns stale approximate fluxes

- Status: confirmed
- Confidence: high
- Affected configuration: `HYDRO_MESHLESS_FINITE_MASS`, nonmagnetic ideal gas,
  without `COOLING` or `GALSF`
- Oracle: MFM contact-frame flux invariant (property)

## Evidence

The nonmagnetic ideal-gas solver first runs HLLC, optionally runs KT, and then
calls `Riemann_solver_exact()` if the approximate star pressure is invalid or
above `press_tot_limiter`. Both approximate solvers write `Riemann_out.Fluxes`
before that final fallback.

The exact solver computes a new contact pressure `P_M` and speed `S_M`. Its
standard sampler immediately returns in MFM mode because no Eulerian face state
is needed, while the wrapper's only face-to-flux conversion was guarded by
`HYDRO_MESHLESS_FINITE_VOLUME`. Consequently, nothing replaced the rejected
HLLC or KT flux before `hydro_core_meshless.h` consumed it.

This violates the MFM contact-frame identities already used by the HLLC path:

```text
mass flux     = 0
momentum flux = P_M n
energy flux   = P_M S_M
```

The stale flux can correspond to a different pressure and contact speed than
the final exact state.

## Reproduce or falsify

Use positive ideal-gas states for which the third HLLC estimate remains positive
but exceeds `press_tot_limiter`. Record `P_M`, `S_M`, and all flux components
immediately before and after `Riemann_solver_exact()`. Before the fix, the star
state changes but the MFM flux components do not.

Falsify the finding by identifying a later MFM conversion that overwrites every
flux component from the final exact state before the hydro pair update, or by
proving that every fallback-triggering approximate state equals the exact state.

## Fix

After exact sampling, the MFM branch now rebuilds the mass, momentum, and energy
fluxes from the final exact `P_M` and `S_M`. The all-vacuum early return also
zeros fluxes in both MFM and MFV modes instead of leaving prior values intact.

## Impact

The old code could report a valid exact pressure while applying the rejected
approximate force and energy transfer. This undermined the solver's last-resort
correctness path precisely on difficult shocks and rarefactions where that path
was intended to be authoritative.
